# 通しの手順（院長が声で通すとき）
## 最短の通し（審査の方・マイクなし）
`http://127.0.0.1:8840/app?typed=1` を開く（右下に文字の入力欄が出る）。
1. 入口で「臨床モード」→ 0123 の行 → 歯科医師の画面。
2. 入力欄に「重要事項を全画面にして」と打つ → 全画面。「アレルギーは？」と打つ → 記録の本文がそのまま出る。
3. 録音は文字で代わりに試せる（下の5以降）。鍵が無いときは質問と下書きの所が「使えません」と出て、見本の記録を見る流れは動く。
4. 受付の画面は入口の「受付モード」から（マウスだけ）。

## ユニットのブラウザで通すとき（G27で整理）
- 開き方は同じ: `http://（この端末の名前または 127.0.0.1）:8840/app`。ブラウザを全画面（F11）にする。マイクの許可は最初に出る確認で「許可」。
- ボタン1・2・3は、ユニットでは手元のボタンに割り当てた Ctrl+Shift+F6・F7・F8。割り当てが無い端末では、キーボードで同じキーを押す。
- 声が使えない・マイクの許可が出ないときは、アドレスの最後に `&typed=1`（すでに `?` があるときは `&typed=1`、無いときは `?typed=1`）を足して文字で通す。
- 通したあとは「撮影の前に戻す.bat」で見本の状態へ戻す（試しの録音は残さない）。

## 院長用・撮影用の手順（声で通す）
前に: `python scripts/seed.py`（初期の状態に戻す。動いているサーバーのデータも初期に戻るので、撮影中や使用中は動かさない）→ ブラウザで `http://localhost:8840/app`（入口の画面が出る）
0. 入口の画面で右の「臨床モード」の札を押す（今日の予約一覧が出る）。左の「受付モード」は受付の端末用で、マウスだけ。氏名が出る患者様一覧から、患者様の受付の画面へ行く。どちらの一覧からも「← 入口へ戻る」で戻れる。
ボタン1・2・3は、それぞれ Ctrl+Shift+F6・F7・F8。どれも「2回押し」（1回目は帯が出るだけ、5秒以内にもう一度）。
1. 予約一覧で 0123 の RCT の行を押す。歯科医師の画面が開く。
2. ボタン2を押す。画面が暗くなり、全画面ボタンの上に「1番」〜、下に質問のボタンが出る。書いてあるとおりに言う（「1番」）→ 重要事項が開く。全画面の中では上の帯だけ暗くなり、その画面で言える例文（「戻して」など）が出る。読んだら「戻して」。
3. ボタン2で「6番」→ 写真が開く（5と8の番号は使わない）。上の帯の例文のとおり「1番と3番を並べて」（または「1番と3番を拡大して」）。「戻して」。いつもの画面から直接なら「写真の3番を拡大して」。「10番」で言える言葉の一覧。「11番」で役割が切り替わる（歯科医師と歯科衛生士）。「12番」か「スマホで写真をやり取り」でスマホの QR が出る。
4. ボタン2で、画面に出た質問（「前回は何をした？」「アレルギーは？」「薬は？」「次回は？」）をそのまま言う → 答えだけが出る（重要事項の帯は上に残らない）。「戻して」の代わりに、ボタン1とボタン2をほぼ同時に押しても戻る（帯も録音も出ない。voice_timing.log に「ボタン同時押し」の行が1行残る）。
5. ボタン1を2回押して録音を始め、診療の話をして、ボタン1を1回押して止める。止めたあとは何も押さない。
   聞き取りのすぐ後に、Claude が文脈から聞き違いを直す（清書。数秒かかる）。話した内容の整理の「録音の区切り」には清書が出て、直した言葉に下線、迷う言葉に印が付く。聞き取ったままの文は「聞き取りのまま」を押すと開く。
   「今日の分をまとめて要約」を押すと、清書から下書きを作り、右下の窓に「下書きができました」と出る。話した内容の整理の欄も、新しい下書きの内容に変わる。
6. 窓を押すか、ボタン2で「下書きを開いて」と言うと、下書きの画面が開く。目で見る（項目は直せる）。
   下書きの画面でボタン2を押すと、ボタンに番号が出る。「1番」で「カルテに記録する」（マウスで押したのと同じ。すぐ記録して来た画面へ戻る）。言葉で記録するときは、ボタン2で「カルテに記録する」と1回言う（「記録」「確定」でもよい。2回言う必要はない）。「他の画面にも入れる」の欄（歯の処置・次回の予定・治療方針）は初めから印が付いていて、入れないものは「3番 外す」で外す。記録するまでは診療メモに入らない。
   「やったこと」に「右下6番の根管充填」のように歯と処置の言葉があると、下に「歯ごとの処置」の欄が出る（初めは印なし）。反映したい行は、ボタン2で出る番号を言って印を付ける。記録すると、歯科医師の画面の今日の処置（記録した「やったこと」の1行）・歯の絵（右下6番が根充済）・治療歴（一番上に今日の行）・治療方針の全画面に入り、受付の次回、「次回は？」の答え、予約一覧の「済み」もそろう。間違えたら、その日のうちにユニットの画面でボタン2「記録を取り消す」と言うと、全部が記録する前に戻り、下書きの画面へ戻る。撮り直すときは「見本の状態へ戻す」（demo_state.py restore）で、歯の状態と治療歴も記録の前に戻る。
   直したいときは「後で直す」（今日の一覧に「大川内先生 追記必要」が赤く点滅）。
7. ボタン3を押して画面を隠す。もう一度ボタン3で戻す（隠している間は名前も情報も出ない）。
8. 予約一覧に戻り、0456 の SPT の行を押す。0123 の情報が残っていないことを見る。
困ったとき:
- 「もう一度お願いします」は聞き取れなかった印。もう一度言う。「まだ開けません」は未対応の画面（丸の2・3・4など）。
- 番号は 1、2、3、4、6、7、9、10、11、12… （5と8は音楽の中で聞き取れないので飛ばす。15、18 などは使う）。ボタン2の番号: 重要事項1、全身既往2、今日の処置3、治療歴4、写真6、話した内容の整理7、歯周検査9、言える言葉10、役割を変える11、スマホ12。写真の札も同じ並び（一覧は1、2、3、4、6、7、9、10…）。「5番」「8番」と言っても何も開かない。
- 丸の番号は出ている間だけ効く。4は「よんばん」、7は「ななばん」と言う。
- 声が使えないときは、画面のアドレスの最後に `&typed=1` を足すと、右下に文字の入力欄が出る。同じ言葉を打つ。
- 見本の「今日」はパソコンの日付。見本へ戻す（下の行）と、その日の日付で作り直される。日付を止めたいときは環境変数 CV_TODAY=2026-11-06 のように指す。
- 撮影の前に、試しに入れたものを消して見本の状態へ戻す: フォルダ scripts の「撮影の前に戻す.bat」をダブルクリック（今のデータベースは C:\hackathon\demo_states\db_backups に日付つきで控えを残す。サーバーは動いたままでよい）。
- 撮影のやり直し: `python scripts/demo_state.py save 名前` で今の状態を写し、`restore 名前` で戻す。
  写す先は `C:\hackathon\demo_states\名前`（環境変数 CV_DEMO_DIR で変えられる）。サーバーは動いたままでよい。
- 予約一覧などで【REC】を押すと、自動で録音の画面（/app）の中に同じ画面が開いて録音が始まる。
