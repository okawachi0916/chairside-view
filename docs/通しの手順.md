# 通しの手順（院長が声で通すとき）
前に: `python scripts/seed.py`（初期の状態に戻す。8840 では院長が自分で）→ ブラウザで `http://localhost:8840/app`
ボタン1・2・3は、それぞれ Ctrl+Shift+F6・F7・F8。どれも「2回押し」（1回目は帯が出るだけ、5秒以内にもう一度）。
1. 予約一覧で 0123 の RCT の行を押す。歯科医師の画面が開く。
2. ボタン2を押す。画面が暗くなり、全画面ボタンの上に丸の番号が出る。見えている番号を言う（「1番」）→ 重要事項が開く。全画面の中に番号は出ない。戻すときは「戻して」。
3. もう一度ボタン2で「5番」→ 口腔内写真が開く。中では「3番を拡大して」で写真の3が大きく出る（写真の番号はここでだけ効く）。「一覧に戻す」。いつもの画面から直接なら「口腔内写真の3番を拡大して」。
4. ボタン2で「前回は何をした？」→ 記録がそのまま出る（Claude は探すだけ）。「戻して」。
5. ボタン1で録音を始め、診療の話をして、もう一度ボタン1で止める。右下の窓が「下書き」になったら開く。
6. 下書きを目で見る（項目は直せる）。ボタン2で「確定する」、続けてもう一度ボタン2で「確定」。
   確定するまでは診療メモに入らない。直したいときは「後で直す」（今日の一覧に「大川内先生 追記必要」が赤く点滅）。
7. ボタン3を押して画面を隠す。もう一度ボタン3で戻す（隠している間は名前も情報も出ない）。
8. 予約一覧に戻り、0456 の SPT の行を押す。0123 の情報が残っていないことを見る。
困ったとき:
- 「もう一度お願いします」は聞き取れなかった印。もう一度言う。「まだ開けません」は未対応の画面（丸の2・3・4など）。
- 丸の番号は、出ている間だけ効く。4は「よんばん」、7は「ななばん」と言う。
- 声が使えないときは、画面のアドレスの最後に `&typed=1` を足すと、右下に文字の入力欄が出る。同じ言葉を打つ。
- 撮影のやり直し: `python scripts/demo_state.py save 名前` で今の状態を写し、`restore 名前` で戻す。
  写す先は `C:\hackathon\demo_states\名前`（環境変数 CV_DEMO_DIR で変えられる）。サーバーは動いたままでよい。
