# チェアサイドビュー 仕様

診療中に手袋のまま使う画面。期間中に新しく制作。自院の既存システムのコードは不使用。

## 決まり
- データは架空のみ。実行時のデータは全部 data/runtime（コミットしない）。
- AI は診断も治療の提案もしない。記録に入れるのは人が確定したものだけ。
- ポートは環境変数 CV_PORT、無ければ 8840。
- app/routers の中のファイルを自動で読み込む（app/main.py は直さない）。

## 画面の部品（data-part）
today-appointment, important, medical-history, today-treatment, treatment-plan, past-notes, treatment-history, intraoral-photos, tooth-chart, spoken-summary, photo-list, perio-exam, next-appointment, booked-appointment
